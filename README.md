# SquareMove

Well, it is a very simple program. it responds to keys and moves!

## how to use it

If you press spacebar it jumps and to move left or right use left and right arrow keys.


## how it works

It listens to keys pressed and changes x, y position according to the key pressed. For the jump it clears, gets drawn up, clears again and gets drawn back down.

## building
```
npm install
node build.mjs
```
